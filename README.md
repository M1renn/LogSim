# LogiSim — пошаговый симулятор логиста с ИИ-персонажами

Обучающая игра для начинающих логистов. Игрок управляет небольшой транспортной компанией в Прибалтике:
получает заявки от клиентов, выбирает грузовик, считает себестоимость рейса и цену для клиента,
переписывается с клиентами, водителями и наставником и следит, чтобы груз пришёл вовремя.

Рабочее название темы: *Development of a Turn-Based Logistics Simulation Game Using Generative AI for Training Beginners*.

## Что уже есть в прототипе

- **Режимы:** 3 обучающих уровня (лёгкий → сложный) и свободная игра с выбором сложности.
- **Главный экран:** карта (Leaflet + OpenStreetMap) с городами, машинами и маршрутами; вкладки «Заказы», «Автопарк», «Рынок и расстояния», «Журнал».
- **Форма расчёта под картой:** расстояние, порожний пробег, вес, расход, цена топлива, ставки водителя и сборов, наценка → разбивка себестоимости и цена для клиента. Сервер сверяет ввод с эталоном и даёт обратную связь (подробность зависит от сложности).
- **Переговоры:** клиент принимает цену, делает встречное предложение или отказывает (у каждого клиента скрытый бюджет).
- **Пошаговость:** 1 ход = 1 игровой час. Машины едут ~65 км/ч, грузятся и разгружаются по 2 ч, после 9 ч за рулём обязательно отдыхают 9 ч, иногда ломаются и стоят в пробках.
- **Пропуск дня:** мгновенно проматывает 24 ч, но с шансом инцидентов (штрафы, порча груза, потеря клиента), а также критического провала, который сразу проваливает уровень.
- **Чаты:** наставник, общий чат клиентов и отдельный чат с каждым водителем. Работают через ИИ-провайдера или через встроенного офлайн-бота.
- **Сохранение:** автосохранение после каждого действия, кнопка «Продолжить» в меню.
- **Десктоп-приложение:** Electron-обёртка, установщик `.exe` с ярлыком на рабочем столе.

## Быстрый старт

Нужен **Node.js 20+** (проверка: `node -v`).

```bash
npm install
npm run dev        # режим разработки: открой http://localhost:5173 в браузере
```

Запуск как приложения в окне:

```bash
npm run app        # собрать и открыть окно Electron
```

Сборка установщика для Windows (появится в папке `release/`):

```bash
npm run dist
```

После установки игра запускается по иконке LogiSim на рабочем столе, как обычная игра.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | Автотест движка: бот проходит уровни по 40 раз, проверяется проверка ошибок расчёта |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm run build && npm run web` | Собранная версия в браузере на http://127.0.0.1:3001 (удобно для демонстрации) |

## Подключение ИИ (бесплатно)

По умолчанию включён **офлайн-бот**: игра полностью работает без интернета и ключей.
Чтобы персонажи отвечали через нейросеть, нажмите **«Настройки ИИ»** и выберите провайдера:

| Провайдер | Где взять ключ | Модель по умолчанию |
|---|---|---|
| Google Gemini | Google AI Studio → Get API key | `gemini-2.5-flash` |
| Groq | console.groq.com → API Keys | `openai/gpt-oss-120b` |
| OpenRouter | openrouter.ai → Keys (модели с суффиксом `:free`) | `google/gemma-4-31b-it:free` |
| Ollama | ключ не нужен, установите Ollama и `ollama pull llama3.2` | `llama3.2` |

Кнопка «Проверить связь» сразу покажет, работает ли подключение. Бесплатные лимиты и названия моделей меняются —
если модель не найдена, впишите актуальную из кабинета провайдера. Если ИИ недоступен, игра автоматически отвечает
офлайн-ботом и пишет об этом в журнал.

Ключ хранится локально в `settings.json` в папке данных приложения (в Electron — `%APPDATA%/LogiSim`,
в браузерном режиме — `./data`).

## Архитектура

```
┌──────────── Electron (окно приложения) ────────────┐
│  React + TypeScript (src/)                         │
│  карта Leaflet · форма расчёта · чаты · вкладки    │
│                 │ fetch /api/*                     │
│  Express-сервер (server/)                          │
│  ├─ game/engine.ts  — пошаговый движок, правила    │
│  ├─ game/data.ts    — города, уровни, сложность    │
│  ├─ ai/chat.ts      — маршрутизация сообщений      │
│  ├─ ai/persona.ts   — системные промпты + контекст │
│  ├─ ai/llm.ts       — клиент OpenAI-совместимых API│
│  ├─ ai/offline.ts   — бот на правилах (fallback)   │
│  └─ storage.ts      — JSON-сохранения и настройки  │
└────────────────────────────┬───────────────────────┘
                             │ HTTPS (по желанию)
                 Gemini / Groq / OpenRouter / Ollama
```

- `shared/` — общие типы и **одна формула расчёта** для клиента и сервера, поэтому калькулятор игрока и эталон не расходятся.
- Все игровые решения (принял ли клиент цену, штрафы, поломки, исход пропуска дня) принимает **движок**, а ИИ только озвучивает персонажей. Это главный ограничитель: модель не может «подарить» игроку деньги или изменить правила.
- Остальные ограничители: системный промпт с запретами и удержанием роли, фильтр ввода (длина, управляющие символы), фильтр вывода (длина, служебная разметка), таймаут запроса и автоматический переход на офлайн-бота.
- Скрытый бюджет клиента не отправляется в браузер (`toPublic()` вырезает его из состояния) и не передаётся в ИИ.

## Формула себестоимости

```
расход с грузом   = базовый расход + вес (т) × 0.4          [л/100 км]
топливо с грузом  = км × расход с грузом / 100 × цена топлива
топливо порожняком = порожние км × базовый расход / 100 × цена топлива
водитель          = (км + порожние км) × ставка водителя
сборы             = (км + порожние км) × ставка сборов
себестоимость     = сумма всего выше
цена клиенту      = себестоимость × (1 + наценка / 100)
```

Опоздание: штраф 20 % цены и −8 репутации. Доставка вовремя: +3 репутации.
Поражение: деньги < 0, репутация 0 или (в уровнях) время вышло / критический инцидент при пропуске дня.

## Известные ограничения прототипа

- Подложке карты нужен интернет (тайлы OpenStreetMap). Без сети города, маршруты и машины всё равно видны на тёмном фоне.
  Для коммерческого релиза тайлы нужно хостить самому или нарисовать собственную карту — правила OSM не разрешают активное использование их серверов.
- Расстояния считаются по прямой × 1.2 (коэффициент извилистости дорог), а не по реальным маршрутам.
- Одна активная игра и одно автосохранение.

## Идеи для развития

- Типы кузовов (тент, рефрижератор) и совместимость с грузами.
- Сборные грузы и несколько точек разгрузки.
- Покупка и аренда машин, зарплаты, кредиты.
- Генерация описаний заказов и событий через ИИ.
- Таблица рекордов и статистика ошибок для преподавателя.
